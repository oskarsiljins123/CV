Dual booting (Windows 11 and cachy os)

Back to the web-CV

As i decided to dual boot a laptop that only has one drive i needed to shrink the main volume that windows is stored on and then use the free space to install the cachy OS on.Unfortunately when i tried to shrink it it refused to shrink beyond a couple of GB although it had 200 GB of free space(the image is inaccurate as its just one from the google rather than my device.After researching the issue i found out that windows creates some unmovable files at the end of the volume that the system is stored in and that prevents me from shrinking the volume correctly.

After spending about an hour trying to remove all the unmovable files i released that there is a simpler way to shrink my volume which is ti just live boot into a Linux environment which i would have to do anyway to install cachy OS and then just use GParted in order to resize my main volume.I did exactly that and proceeded to installing the cachy OS

After the successful instillation i thought that i would need to install ML4W dot files like i used to when using hyprland but i noticed that a new cachy OS update made the distribution be very customisable without any dot files so i just configured some extra keybindings as well as changed the theme to a custom one.

I also installed some necessary packages like the software that makes screenshots , vs code alternative as well as chrome for easier website development and maintenance
